# Land Area Converter

A web application that converts land area between square metres,
acres and hectares.

## Features

- Convert between all three supported units.
- Accept decimal values.
- Prevent empty or negative inputs.
- Display results rounded to four decimal places.
- Responsive layout for smaller screens.

## Technologies

- HTML: page structure and form controls.
- CSS: styling and responsive layout.
- JavaScript: input validation and conversion calculations.

## How to run

Open index.html in a web browser.

## Conversion method

The application converts the input into square metres, then
converts that value into the selected target unit.

- 1 acre = 4046.8564224 square metres.
- 1 hectare = 10000 square metres.

## Example

2 acres ≈ 0.8094 hectares.
